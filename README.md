# Dashboard Visualisasi Data Cuaca — CASE3

## Deskripsi Proyek
Proyek ini merupakan implementasi analisis dan visualisasi data cuaca menggunakan Python. Data diolah dan disajikan melalui dashboard interaktif berbasis Streamlit untuk membantu pengguna memahami informasi cuaca melalui berbagai bentuk visualisasi.

## Tujuan
- Melakukan pengolahan dan analisis terhadap dataset cuaca.
- Menyajikan informasi cuaca dalam bentuk visualisasi yang mudah dipahami.
- Mengidentifikasi pola dan informasi berdasarkan data pengamatan cuaca.
- Mengembangkan dashboard interaktif sebagai media penyajian hasil analisis data.

## Fitur Dashboard
- Menampilkan ringkasan informasi dari dataset cuaca.
- Menyajikan visualisasi data cuaca menggunakan grafik interaktif.
- Menampilkan informasi terkait suhu dan kelembaban.
- Menyediakan tampilan dashboard yang interaktif dan mudah digunakan.

## Teknologi yang Digunakan
- Python
- Jupyter Notebook
- Pandas
- Streamlit
- Plotly
- Git dan GitHub

## Struktur File
- `analisis_data.ipynb` : Notebook untuk proses analisis data.
- `app.py` : Source code aplikasi dashboard.
- `dataset_cuaca.csv` : Dataset yang digunakan.
- `requirements.txt` : Daftar library yang dibutuhkan.

## Dataset
Dataset yang digunakan dalam proyek ini adalah `dataset_cuaca.csv`, yang berisi data cuaca sebagai sumber utama dalam proses pengolahan, analisis, dan visualisasi data.

## Cara Menjalankan Proyek
1. Clone repository:
   ```bash
   git clone https://github.com/yenseason/CASE3.git
   ```
2. Masuk ke folder proyek:
   ```bash
   cd CASE3
   ```
3. Install library:
   ```bash
   pip install -r requirements.txt
   ```
4. Jalankan dashboard:
   ```bash
   streamlit run app.py
   ```
